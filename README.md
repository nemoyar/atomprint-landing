# АТОМПРИНТ - прототип лендинга

Прототип для показа концепции. Цены, сроки и цифры демонстрационные, форма никуда не отправляет.

Стек: Vite, React 19, Tailwind 4, Framer Motion, three.js + @react-three/fiber/drei/postprocessing.

    npm install
    npm run dev       # http://localhost:5173
    npm run build     # статика в dist/

Тексты, тарифы и хотспоты - `src/data.js`. 3D-модель МФУ - `src/three/Printer.jsx`.
